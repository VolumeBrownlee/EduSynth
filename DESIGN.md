# Design System: EduSynth

> Single source of truth for visual design decisions across EduSynth. Use this file to brief Google Stitch when generating new screens, and as the reference any contributor reaches for before adding UI.
>
> Generated by the `stitch-skill` workflow. Reflects the post-impeccable + post-taste-skill state of the codebase.

---

## 1. Visual Theme & Atmosphere

EduSynth is an **AI-native study platform for university students** — lecturer-grounded tutoring, AI-calibrated assessment, privacy-conscious gamification. The interface must feel **scholarly with confident gamified moments**: a serious study tool that respects the reader's attention, not a Silicon Valley pitch deck and not a children's app.

**Density:** *Daily-App Balanced* (4 / 10). Dense enough that a student can compare notes, the AI Tutor, and their progress at a glance; never so packed that any single surface becomes a noisy dashboard. Reading-fatigue is the enemy.

**Variance:** *Offset Asymmetric* (8 / 10). Grid columns favour `1fr 1.4fr 1fr` or `2fr 1fr` over equal thirds. The 3-up "identical card row" is banned. Symmetry is reserved for stat tiles where parity *is* the message.

**Motion:** *Fluid CSS* (6 / 10). Spring physics on every interactive element. Perpetual micro-motion is **earned, not decorative** — limited to the Ready-Score gauge ring, the "Today's Focus" live indicator, and the footer online status. No floating particles. No scanlines. No gradient meshes. The page should feel alive without feeling busy.

The atmosphere reference is **Linear meets Anki meets a well-edited academic monograph**: utility-first surfaces, real type hierarchy, restrained colour, gamified accents that signal *progress earned*, not *button mashed*.

## 2. Color Palette & Roles

All colours are stored as HSL custom properties in `app/src/index.css`. Stitch should receive the hex approximations below; the running app derives the same values from the tokens for theme-switching.

### Light theme — "Alabaster"

| Token | Hex | Role |
|---|---|---|
| **Canvas Mist** | `#F8FBFA` | Primary background — almost-white, faintly tinted toward the brand teal hue. Never `#FFFFFF`. |
| **Card Surface** | `#FFFFFF` | Opaque card fill. Glass effects are reserved for genuine overlays only. |
| **Ink Slate** | `#161E2F` | Primary text, near-ink with a faint cool tint. Never `#000000`. |
| **Muted Stone** | `#EEF3F2` | Subtle surface tint — bg of muted cards, footer dividers. |
| **Secondary Steel** | `#5B6776` | Secondary text, descriptions, metadata, timestamps. |
| **Whisper Border** | `#DCE2E6` | 1 px structural lines. Card borders, dividers, table cells. |
| **Brand Teal** | `#178D82` | Primary brand colour. CTAs, focus rings, active nav, the Ready-Score "ready" state. The single dominant accent. |
| **XP Amber** | `#DB840F` | Gamification accent. Streak fire, XP titles, "Today's Focus" highlight. Used ≤ 10% of any view. |
| **Lecturer Purple** | `#8454DD` | Role-tagging for lecturer surfaces and badges. Never used for student-facing emphasis. |
| **Live Success** | `#1DA67A` | Online indicator, success-state ticks, "ready" toasts. |
| **Information Cyan** | `#1592C2` | Chart accent (analytics view), informational toasts. |
| **Destructive Coral** | `#E5414C` | Error toasts, delete buttons, validation failures. Use sparingly — never as decoration. |
| **Gold / Silver / Bronze** | `#E6A012` / `#C5C7CC` / `#A65A1A` | Leaderboard top-3 indicators only. |

### Dark theme — "Obsidian"

| Token | Hex | Role |
|---|---|---|
| **Canvas Ink** | `#0F141B` | Primary background — deep ink with a faint cool tint. Never `#000000`. |
| **Card Surface** | `#161B23` | One stop above the canvas — opaque, never translucent. |
| **Foreground Mist** | `#EFF3F2` | Primary text — soft white with a teal-leaning tint. Never `#FFFFFF`. |
| **Muted Slate** | `#1D2229` | Tinted muted surfaces. |
| **Secondary Steel** | `#9CA3B0` | Secondary text. |
| **Whisper Border** | `#2C3138` | Structural lines, opacity ~ 1. |
| **Brand Teal** | `#36D9C3` | Brighter for dark-mode contrast against the deep canvas. |
| **XP Amber** | `#F7B635` | Brighter for dark-mode contrast. |
| **Lecturer Purple** | `#A28EF1` | Brighter lecturer accent. |

**Banned in EduSynth:** `#FFFFFF`, `#000000`, AI purple `#6366F1` / `#7C3AED` as decoration, indigo-to-purple gradient text, neon outer glows, any unprincipled `bg-zinc-*` / `text-slate-*` Tailwind references that bypass the token system. **The token system is load-bearing.** Components reach for `hsl(var(--*))`, never raw hex.

## 3. Typography Rules

| Role | Font | Source | Weights |
|---|---|---|---|
| **Display** | `Inter Tight` | Google Fonts | 500 / 600 / 700 / 800 |
| **Body** | `Geist` | Google Fonts | 300 / 400 / 500 / 600 / 700 |
| **Mono** | `Geist Mono` | Google Fonts | 400 / 500 / 600 |

**Scale (Tailwind tokens):**

| Token | Size | Use |
|---|---|---|
| `text-2xs` | 12 px / 16 lh | Labels, badges, tabular metadata. Hard floor. |
| `text-xs` | 13 px / 18 lh | Chip text, dense list rows. |
| `text-sm` | 14 px / 20 lh | Body small, secondary content. |
| `text-base` | 16 px / 24 lh | Body default. |
| `text-lg` | 18 px / 26 lh | Card subtitles, paragraph leads. |
| `text-xl` → `text-2xl` | 20 → 24 px | Section heads. |
| `text-3xl` → `text-5xl` | 30 → 48 px | Page titles, hero numbers. |

**Hierarchy rule:** weight + colour first, scale second. The first H1 on a page must **not scream**. Display font sits at `tracking-tight leading-none` for large sizes; body sits at `leading-relaxed max-w-[65ch]`.

**Banned:** `Inter` (vanilla), `Roboto`, `Arial`, any system font as display, `Times New Roman`/`Georgia`/`Garamond` serifs, `Lobster`-style novelty faces, sub-12 px text anywhere except specific captions, gradient text on any heading.

**Numbers:** apply `tabular-nums` everywhere a value can change at runtime (XP, scores, percentages, streaks, leaderboard ranks, timer counts). Use `Geist Mono` for any column where number alignment matters.

## 4. Component Stylings

### Buttons

- **Primary** — `bg-primary text-primary-foreground`. No outer glow. Tactile `active:scale-[0.98]` on press (baked into the Button primitive).
- **Outline** — `border bg-background hover:bg-accent hover:text-accent-foreground`. Used for secondary nav actions.
- **Ghost** — `hover:bg-accent hover:text-accent-foreground`. Used for icon-only controls in chrome (header, footer).
- **Destructive** — `bg-destructive text-white hover:bg-destructive/90`. Confirmations only — never as primary CTA.
- **Sizes** — minimum `h-9` (36 px) for any user-facing action. Icon-only controls promoted to `h-10` (40 px). Header chrome `h-10 w-10`. Never go below `h-8` for interactive surfaces.
- **Focus** — every interactive element shows `focus-visible:ring-2 focus-visible:ring-ring/60` from a single shared focus-ring utility. No exceptions.

### Cards

Two utility levels in `index.css`:

- **`.card-elevated`** — opaque `bg-card`, 1 px `border-border`, subtle theme-aware shadow (`0 1px 2px ... + 0 1px 3px ...`). The default. Use for *most* surfaces.
- **`.bento-card`** — opaque `bg-card`, 1 px `border-border`, `border-radius: 1.5rem`, **diffusion shadow** (`0 20px 40px -15px ...`). Reserved for hero panels and "moment" surfaces — Dashboard hero, "Today's Focus" card.

Cards are used **only when elevation communicates hierarchy**. Inline content with `border-t` dividers or pure negative space is the preferred alternative for dense data lists. Nested cards are always wrong.

### Inputs

- Label sits **above** the input (never floating, never inside).
- Input itself: `h-9 rounded-md border border-input bg-background`. Focus uses the shared focus-ring utility.
- Helper text optional, sits **below** the input, `text-xs text-muted-foreground`.
- Error text below in `text-destructive`, with `aria-invalid` flipping the border colour.
- Standard `gap-2` between label / input / helper-or-error.

### Loaders

Skeletal placeholders that **match the layout of the loaded content** — same dimensions, same rhythm. Plain `bg-muted animate-pulse rounded-md` blocks. No circular spinners (banned). The Dashboard shows skeleton stat-tiles, skeleton hero, skeleton chart that resolve smoothly into the real content.

### Empty States

Composed compositions, not stub text. Pattern: small lucide icon, primary heading ("No past papers yet"), one-line `text-sm text-muted-foreground` instruction ("Your lecturer hasn't uploaded any past papers for this subject"). Never "No data found" or a sad-emoji icon.

### Error States

Inline. Toast for transient (`ToastContainer`), banner for persistent. Always pair the message with an action ("Try again", "Contact lecturer"). Never a bare red exclamation.

### Badges

`Badge` shadcn primitive, customised: `text-2xs h-4–5 px-1.5`, role-coloured backgrounds (`bg-primary/10 text-primary border-primary/30` etc.), Lucide icon prefix where the meaning is icon-able.

### Modals

Open via Radix `Dialog`. Spring-physics entrance (`scale 0.92 → 1`). `glass-overlay` utility for the backdrop tint (the *only* sanctioned use of glassmorphism in EduSynth). `rounded-xl` body. Close on Escape, click-outside, and explicit X.

## 5. Layout Principles

- **Containment:** `max-w-7xl mx-auto` for every full-page surface. Hero panels get `p-6 md:p-8`; content panels get `p-4 md:p-6`.
- **Grids:** CSS Grid for any multi-column composition. Never `calc()` percentage hacks in Flexbox. Asymmetric column templates (`grid-cols-[1fr_1.4fr_1fr]`, `grid-cols-[2fr_1fr]`) by default; symmetric grids only when parity *is* the message (stat tiles).
- **Banned:** centered Hero layouts, 3-up identical card grids, `h-screen` (use `min-h-[100dvh]` to avoid iOS Safari jump), nested cards, side-stripe borders > 1 px.
- **Overlap:** every element occupies its own spatial zone. No absolute-positioned text stacking onto images.
- **Mobile collapse:** every multi-column layout collapses to a single column below `md:` (768 px). Tested on iPhone 13 Safari and Pixel 7 Chrome.
- **Touch targets:** 40 px minimum for any tappable control. Promoted to 44 px on touch-only viewports where space allows.
- **Rhythm:** consistent vertical spacing scale (`gap-3`, `gap-4`, `gap-5`, `gap-6` for major sections). Avoid `gap-1.5` / `gap-2.5` mixing.

## 6. Motion & Interaction

### Engine

- **Library:** Framer Motion. Imported as `motion` and `AnimatePresence`.
- **Default transition:** `{ type: 'spring', stiffness: 110, damping: 18, mass: 0.9 }`. Linear easing is banned for any layout-affecting motion.
- **Stagger:** parent uses `staggerChildren: 0.06, delayChildren: 0.02`. Lists and grids never mount instantly.

### Perpetual micro-motion (the only sanctioned infinite loops)

| Animation | Where | Why |
|---|---|---|
| `.ring-pulse` | Ready-Score gauge, XP-gain moments | Signals "live progress" |
| `.breathe` | "Today's Focus" indicator, footer online dot | Signals "system alive" |
| `.progress-shimmer` | Ready-Score progress fill | Reinforces the fill is *active* |
| `.typing-dot` (×3) | AI Tutor thinking state | Conveys waiting for response |

Everything else is *event-driven*: `float-xp` fires once when XP is awarded, `confetti-fall` once on a milestone, `scale-in` once on modal mount.

### Hardware acceleration

Only `transform` and `opacity` are animated. `width`, `height`, `top`, `left` are never animated — use `scale` and `translate` instead. `will-change` applied sparingly (only on confirmed performance hot-spots).

### Reduced motion

`@media (prefers-reduced-motion: reduce)` collapses all animation-duration to `0.01ms`. Respected globally in `index.css`.

## 7. Anti-Patterns (Banned)

These are non-negotiable. Every contributor and every AI screen generator must avoid them.

**Visual / CSS**
- No `#FFFFFF`, no `#000000` — always tinted neutrals
- No neon outer glows / decorative `box-shadow` glows
- No oversaturated accent colours (>80% saturation)
- No gradient text on headings
- No glassmorphism as the default card style — only on `glass-overlay` for genuine overlays
- No custom mouse cursors
- No animated radial-gradient mesh backgrounds
- No HUD scanlines, watermarks, or noise overlays as decoration
- No side-stripe coloured borders > 1 px

**Typography**
- No `Inter`, `Roboto`, `Arial` — always `Geist` body + `Inter Tight` display
- No oversized H1s that compete with content
- No serif fonts in dashboard surfaces
- No sub-12 px text for body or controls

**Layout & spacing**
- No 3-column equal-card "feature row"
- No centered Hero layouts (use split, left-aligned, or asymmetric whitespace)
- No `calc()` percentage hacks in Flexbox math
- No `h-screen` (iOS Safari jump) — use `min-h-[100dvh]`
- No overlapping text on images
- No nested cards

**Content / data**
- No emojis anywhere — replace with Lucide icons
- No generic names ("John Doe", "Jane Smith", "Acme Inc")
- No fake-perfect numbers (`99.99%`, `50%`, `100%` as defaults) — use organic real values
- No AI copywriting clichés ("Elevate", "Seamless", "Unleash", "Next-Gen")
- No filler UI text ("Scroll to explore", "Swipe down", bouncing chevron icons)
- No `Unsplash` direct links (broken often) — use `picsum.photos/seed/{slug}/{w}/{h}` or local assets

**Components**
- No `Lucide` user icon as default avatar — use 2-letter initials in `Avatar` primitive
- No animated counters on stats that don't actually count up over time
- No `shadcn/ui` defaults straight from the kit — customise radius, colour, shadow to match this system

## 8. Stitch Briefing Template

When prompting Google Stitch to generate a new EduSynth screen, paste this template above the screen-specific instructions:

```
DESIGN SYSTEM CONTEXT — EduSynth

Mood: scholarly with confident gamified moments. Density 4. Variance 8. Motion 6.
Background: tinted near-white (#F8FBFA light) or deep tinted ink (#0F141B dark) — never #FFFFFF or #000000.
Primary accent: brand teal #178D82 (light) / #36D9C3 (dark). Use sparingly; one accent ≤ 10% of view.
Gamification accent: XP amber #DB840F (light) / #F7B635 (dark). Use for streak / XP / "Today's Focus" only.
Display font: Inter Tight (500–800). Body font: Geist (400–700). Mono font: Geist Mono.
Layout: 12-col CSS Grid, asymmetric column templates preferred, max-w-7xl containment, mobile collapses to single column.
Cards: opaque, 1px border, 24px radius for hero panels (diffusion shadow), standard radius otherwise. No glassmorphism. No nested cards.
Buttons: tactile active:scale-[0.98]. No glows.
Motion: spring physics { stiffness: 110, damping: 18 }. Perpetual loops only on Ready-Score gauge, live indicators, AI tutor thinking dots.
Banned: emojis, Inter font, #000/#fff, neon glows, gradient text, 3-up equal grids, centered heroes, custom cursors, AI copywriting clichés, generic placeholder names.
```
